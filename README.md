# HL_Ezing for AviUtl2

HL_Ezing は、AviUtl2 のトラックバーに対してベジェ、振動（Elastic）、バウンス（Bounce）の各種イージングカーブを設定・適用できるプラグインです。

---

## 主な機能

- **3 種類のイージングモード**
  - **ベジェ**: 複数のアンカーとハンドルで自由度の高い減速・加速カーブを作成。
  - **振動**: 振幅・周波数・減衰をドラッグ操作で設定する振動イージング。
  - **バウンス**: 跳ね返り係数や周期を視覚的に編集できるバウンスイージング。
- **カーブIDによる共有編集**
  - カーブごとに ID が割り当てられ、ヘッダーの数値欄への入力またはドラッグで編集する ID を切り替えられます。
  - 同じ ID を適用した複数のトラックバーは、その ID のグラフを変更すると一斉に変化します。
  - カーブを再利用したい場合は、既存の ID を選んで別のトラックバーへ適用するだけです。
- **中間点ごとのイージング**
  - 既存の開始点・終了点・中間点の値を保持したまま、移動方法だけを HL_Ezing に差し替えます。
  - 中間点ごとに別のカーブIDを割り当てられます。
  - シークバーを移動してからドラッグすると、その位置の区間だけを上書きします。
  - 画面下の区間バーから区間を選択できます。
- **トラックピッカー適用**
  - 「適用」ボタンをクリックすると、選択オブジェクト内のトラックバー一覧を表示し、1つのプロパティへ適用できます。
  - `Shift` キーを押しながら項目を選択すると、ピッカーを閉じずに複数のプロパティへ連続して適用できます。
  - 最下部の「全てに適用」で、選択オブジェクトの全トラックバーへ一括適用できます。
- **ドラッグ&ドロップ適用**
  - 「適用」ボタンをオブジェクト設定のトラックバーまでドラッグし、その場でドロップするとカーブを適用できます。
  - クリックした場合は従来どおりトラックピッカーが開きます。
  - ドラッグ中はドロップ先の行が枠でハイライトされます。
  - オブジェクト設定に表示されているトラックバーが対象です。
  - 設定でD&D自体を無効化できます。
  - グループ化されたX/Y/Zなどへドロップした際、まとめて適用するかを設定で選べます。
- **右クリックコンテキストメニュー適用**
  - オブジェクト設定ウィンドウのトラックバーを右クリックし、「HL_Ezing → このトラックバーに最後のカーブを適用」を選択することでも適用できます。
- **キー操作によるグリッドスナップ**
  - `Shift` キー: Y軸方向の移動をグリッド線へスナップ。
  - `Ctrl` キー: X軸方向の移動をグリッド線へスナップ。
  - `Alt` キー: 何もない場所をドラッグしてパン操作。
- **カーブ編集の Undo / Redo**
  - `Ctrl+Z` で元に戻す、`Ctrl+Y`（または `Ctrl+Shift+Z`）でやり直し。
  - ドラッグ1回、アンカー追加・削除、プリセット読み込みなどを1ステップとして記録します。
- **ハンドルの分離 / 統合**
  - グラフ上のアンカーやハンドルを右クリックし、「ハンドルを分離 / 統合」で切り替え。
  - 統合状態では左右のハンドルの向きが反対に揃います。長さは左右で独立して変更できます。
- **AviUtl2 本体の Space 再生**
  - グラフ操作後にそのまま `Space` を押すと、AviUtl2 本体の再生 / 停止が動作します。
- **プリセット管理**
  - 作成したカーブをサムネイル付きで保存・並べ替え。
  - 設定画面からプリセットカードの表示サイズ（スライダー）や位置（右・左・上・下）を変更可能。
  - メイン領域とプリセット欄の仕切りバー中央にある矢印ボタンで、表示 / 非表示を切り替え可能。
- **プロジェクト保存連携**
  - 使用したカーブデータと最後に適用した ID は AviUtl2 のプロジェクトファイル内に保存されます。

## 動作環境

- **対応 OS**: Windows 10 / 11 (64bit)
- **対象ソフト**: AviUtl2
- **必須コンポーネント**: Microsoft Edge WebView2 Runtime（Windows 11 では標準搭載）

## インストール方法

1. リリースパッケージを [Releases](https://github.com/Hallkun19/HL_Ezing-for-aul2/releases/latest) からダウンロードします。
2. ダウンロードしたリリースパッケージを、AviUtl2のウィンドウへドラッグアンドドロップしてインストールします。

## 基本的な使い方

### 1. カーブIDを切り替える

1. `HL_Ezing` ウィンドウを開きます。
2. ヘッダーの数値欄に、編集したいカーブ ID を入力します。左右にドラッグして数値を変更することもできます。
3. 数値を切り替えると、その ID のカーブがグラフに読み込まれます。
4. 上部のドロップダウンでモード（「ベジェ」「振動」「バウンス」）を選択し、グラフ領域でアンカーやハンドルをドラッグして編集します。

**ID のグラフを変更すると、その ID を適用しているすべてのトラックバーへ即座に反映されます。**
別のトラックバーへ同じ動きを適用したい場合は、同じ ID を選択したまま「適用」してください。

存在しない ID を入力した場合は、現在のグラフを複製して新しい ID を作成します。

### 2. トラックバーへの適用

- **方法 A: 「適用」ボタン（トラックピッカー）**
  1. タイムライン上で対象のオブジェクトを選択します。
  2. `HL_Ezing` の「適用」ボタンをクリックします。
  3. 表示された一覧から適用したいプロパティ（例: `標準描画 / X`）をクリックします。
  4. 同じ名前のトラックバーが複数ある場合は `（2番目）` のように表示され、選択したものに正しく適用されます。
  5. `Shift` キーを押しながら選択すると、一覧を閉じずに連続して他のプロパティへも適用できます。
  6. 最下部の「全てに適用」を選択すると、選択オブジェクトの全トラックバーへ一括適用されます。

- **方法 B: トラックバーの右クリックメニュー**
  1. オブジェクト設定ウィンドウ内の対象トラックバーを右クリックします。
  2. メニューから `HL_Ezing` → `このトラックバーに最後のカーブを適用` を選択します。

- **方法 C: ドラッグ&ドロップ**
  1. オブジェクト設定ウィンドウで対象のトラックバーを表示します。
  2. `HL_Ezing` の「適用」ボタンを押したまま、トラックバーまでドラッグします。
  3. トラックバー上でマウスボタンを離すと、そのトラックバーへ適用されます。
  4. ドラッグをやめたい場合は、トラックバー以外の場所で離してください。

適用後は、トラックバーの値（開始点・中間点・終了点）はそのまま維持されます。
カーブを変更したい場合は、そのトラックバーに適用されている ID を選択してグラフを編集してください。

## 中間点ごとの動作について

HL_Ezing は、トラックバーの既存の値を次のように扱います。

```text
開始値, 中間点1, 中間点2, ..., 終了値
```

各区間（開始値→中間点1、中間点1→中間点2、…）に対して、同じカーブを 0.0〜1.0 として適用します。
そのため、中間点を追加・移動しても、それぞれの区間でイージングが個別に動作します。

適用時に「中間点無視」や時間制御リンクが設定されている場合は、中間点ごとの動作を優先するため、それらの設定を解除します。

## グラフエリアの操作方法

- **アンカーの追加**: 線上の任意の場所をダブルクリック
- **アンカーの削除**: 既存のアンカーをダブルクリック、またはアンカーを右クリックして「アンカーを削除」
- **始点・終点の移動**: 始点と終点は上下に自由に移動でき、移動に合わせてカーブと適用時の動きも追従します（X位置は固定）
- **視点移動（パン）**: 何もない場所で `Alt` キーを押しながらドラッグ、またはマウス中ボタンドラッグ
- **拡大・縮小（ズーム）**: マウスホイール回転
- **視点リセット**: 視点移動時に左上に表示される「視点リセット」ボタンをクリック
- **グリッドスナップ**:
  - `Shift` を押しながらドラッグ: Y軸方向をグリッド目盛りへ吸着
  - `Ctrl` を押しながらドラッグ: X軸方向をグリッド目盛りへ吸着
- **ハンドルの分離 / 統合**: アンカーまたはハンドルを右クリックし、メニューから切り替え
  - 統合状態では、片方を動かすともう片方の向きも反対に揃います。長さは独立です
- **Undo / Redo**: `Ctrl+Z` / `Ctrl+Y`（`Ctrl+Shift+Z` も可）

---

## プリセットの管理

- **保存**: フッターの「プリセット保存」ボタンをクリックし、名前を入力して保存。
- **読み込み**: プリセット一覧のカードをクリック。現在の ID に読み込まれます。
- **並べ替え**: プリセットカードをドラッグ＆ドロップして順番を変更。
- **削除**: プリセットカード上で右クリックし、「プリセットの削除」を選択。
- **サイズ変更**: 設定アイコンから「プリセットのボックスサイズ」スライダーで大きさを調整。
- **表示 / 非表示**: メイン領域との仕切りバー中央の矢印ボタンで切り替え。非表示時は画面端に残る矢印で再表示できます。

---

## 設定

ヘッダー右側の設定アイコンから各種動作をカスタマイズできます。

- **ドラッグ&ドロップ適用**: ON / OFF。OFFでもクリック適用・ピッカー・右クリック適用は使えます。
- **X/Y/Zなどのグループ項目へまとめて適用（D&D）**: ONにすると、グループ化された項目へドロップした際に同じグループ全体へ適用します。
- **プリセットパネル位置**: 右 / 左 / 上 / 下
- **プリセットのボックスサイズ**: カードの表示サイズを 40px 〜 140px で調整
- **グリッド分割数 X / Y**: グラフ領域の背景目盛り分割数
- **カーブ描画精度**: グラフ曲線の描画解像度

## 制限事項

AviUtl2 の公開 SDK には、ウィンドウ外のトラックバー位置を取得する API がありません。
そのためドラッグ&ドロップ適用は、AviUtl2 の非公開 UI 構造を実行時に解析して実装しています。
AviUtl2 のバージョンアップで内部構造が変わると、ドラッグ適用だけが使えなくなる場合があります。
その場合もクリック適用・トラックピッカー・右クリックメニューは利用できます。

診断方法と、バージョンアップ時の更新手順は
[`docs/DRAG_AND_SEGMENTS.md`](docs/DRAG_AND_SEGMENTS.md) を参照してください。
技術的な詳細は [`docs/TRACKBAR_DRAG.md`](docs/TRACKBAR_DRAG.md) にあります。

## トラブルシューティング

- **GUI ウィンドウが表示されない / 真っ白になる**:
  - Microsoft Edge WebView2 Runtime がインストールされているか確認してください。
- **移動方法に `HL_Ezing` が表示されない**:
  - `Script/HL_Ezing/HL_Ezing.tra2` が正しいパスに配置されているか確認し、AviUtl2 を再起動してください。
- **イージングが適用されない**:
  - タイムライン上でオブジェクトが選択されているか、またはオブジェクト設定ウィンドウで対象のオブジェクトが開かれているか確認してください。
  - ヘッダーのカーブIDが入力されているか確認してください。
